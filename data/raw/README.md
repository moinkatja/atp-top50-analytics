# Raw data

Source: [Jeff Sackmann — tennis_atp](https://github.com/JeffSackmann/tennis_atp) (CC BY-NC-SA 4.0).

Files used by this project:

| File | Purpose |
|------|---------|
| `atp_players.csv` | Player metadata |
| `atp_matches_2015.csv` … `atp_matches_2025.csv` | Match results |
| `atp_rankings_10s.csv`, `atp_rankings_20s.csv` | Weekly rankings |

Download the latest files from the repo above and place them in this folder, then run `scripts/build_database.py`.
